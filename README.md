# Сложно сосредоточиться

Адаптивный лендинг о концентрации внимания со светлой и тёмной темами. Тема переключается автоматически по системным настройкам или вручную кнопками «День», «Авто» и «Неон».

Вёрстка mobile first: брейкпоинты 768 и 1024 пикселя, раскладка на CSS Grid, цвета тем вынесены в CSS-переменные.

Репозиторий: https://github.com/HardStormer/slozhno-sosredotochitsya-ad
